# ==============================================================================
# NIEVO MCP Secrets Template (mcp_secrets_example.txt -> mcp_secrets.env)
# ==============================================================================
# Uso:
#   1. Garanta que `mcp_secrets.env` esteja listado no `.gitignore` do projeto.
#   2. Copie este molde para `mcp_secrets.env` na raiz do projeto (escopo local).
#   3. Preencha manualmente apenas os tokens dos servidores que você utiliza.
#   4. Execute `docker mcp profile show nievo_ai` para confirmar os nomes exatos
#      das chaves exigidas pela versão atual do profile OCI puxado.
#
# ATENCAO:
#   - NUNCA commite `mcp_secrets.env` no Git.
#   - NUNCA solicite ao agente de IA que leia ou exiba o conteúdo de `mcp_secrets.env`.
#   - Este arquivo alimenta exclusivamente o argumento `--secrets` em
#     `.agents/plugins/nievo/mcp_config.json` (escopo do projeto, nunca global).
# ==============================================================================
